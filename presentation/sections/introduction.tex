\section{Previous Work: The Foundation}

\begin{frame}{Initial Phase: Basic Infrastructure}
    \begin{itemize}
        \item \textbf{Core Framework}: Built with Next.js (App Router) for high performance and SEO optimization.
        \item \textbf{Database}: Integrated Supabase for secure user authentication and real-time product database management.
        \item \textbf{Barcode Integration}: Implemented \texttt{@zxing/library} for high-speed barcode scanning on mobile and desktop.
        \item \textbf{Health Rules Engine}: Established a deterministic rule-based system to flag products based on user-defined allergens and medical conditions.
    \end{itemize}
\end{frame}
